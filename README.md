Ce projet a pour but de présenter les solutions du casse tête : la cité infernale.

Il y a des nombreuses solutions à ce casse tête.
Il y a 13 configurations de départ et pour chaqu'une, on présentera toutes les solutions.

Le jeu est constitués de 9 pièces de forme différentes.
Dans cette solution, les pièces sont numéroté de 1 à 9.
Chaque pièce est en 3 dimensions mais ne peut être posée à plat que d'une seule façon.
Il existe donc pour chaque pièce que 4 positions possibles
(ou 2 dans le cas de pièces présentant un centre de symétrie)
qui se déduisent par rotation.
